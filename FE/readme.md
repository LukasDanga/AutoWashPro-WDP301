Frontend demo: Đăng nhập / Đăng ký (dark UI)

How to run:

1. Open `FE/index.html` in your browser (double-click or serve via a static server).
2. Use the tabs to switch between "ĐĂNG NHẬP" and "ĐĂNG KÝ".
3. Click "Thử nghiệm" in the quick-fill card to auto-fill demo credentials.

Notes:
- This is a static demo (no backend). Integrate with existing BE endpoints in `BE/` as needed.
